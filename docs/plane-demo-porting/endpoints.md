# Danh mục endpoint và đầu việc Lancity

[Về kế hoạch chuyển đổi](../plane-demo-porting.md) · [Sơ đồ call graph](../plane-demo-backend.html)

Danh mục gồm 728 mục method/route từ resolver và controller của Plane Demo. Mỗi mục trỏ về checkbox của function hoặc adapter kế thừa. Các biến thể URL dùng chung một đầu việc khi cùng trỏ một function. URL trong bảng là của Plane Demo để đối chiếu.

## Path Lancity khác path Plane

URL trong các bảng dưới là của Plane Demo, dùng để đối chiếu. Lancity phục vụ client web và mobile riêng nên path khác Plane. Danh sách path thật nằm ở `apiV1Routes` trong [`src/data/linkto.ts`](../../src/data/linkto.ts) và các router trong [`src/server/api/v1/routes/`](../../src/server/api/v1/routes). Mục `[x]` ở đây nghĩa là hành vi đã chuyển, không nghĩa là path giống Plane. Không thể suy ra tự động từng route vì một router Lancity thay nhiều route Plane, nên chỉ ghi quy tắc đổi tên chung:

| Plane | Lancity (dưới `/api/v1`) |
| --- | --- |
| `/api/workspaces/<slug>/...` | `/workspaces/:slug/...` |
| `/api/workspaces/<slug>/projects/<uuid>/...` | `/workspaces/:slug/projects/:projectId/...` (`linkto.apiProject`) |
| `work-items`, `issues` | `issues` (`/issues/:issueId`), id số |
| `cycle-issues`, `module-issues` | `/cycles/:cycleId/cycle-issues`, `/modules/:moduleId/module-issues` |
| `inbox-issues` | `intakes` và `intake-issues` (`inbox-issues` vẫn có) |
| `/api/users/me/...` | `/users/...` (token ở `/users/api-tokens`) |
| `/api/instances/...` | `/instances/...` |
| `/api/assets/v2/...` | `/assets/...` và `/workspaces/:slug/assets/...` |
| `/api/public/anchor/<anchor>/...` | `/public/anchor/:anchor/...` |
| Live `/live/...` | `/live/health`, `/live/collaboration`, `/live/convert-document`, `/live/force-close` |
| Tham số `<uuid:...>` | số nguyên tự tăng |

Lỗi trả về dạng `{ "error": { "code", "message", "details" } }`. Xác thực bằng cookie phiên hoặc header `X-API-Key`. Xem thêm [review-fixes](./handoff/review-fixes.md#c-lệch-có-chủ-đích-giữ-nguyên).

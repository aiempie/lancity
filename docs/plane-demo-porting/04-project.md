# Project, thành viên và cấu hình project

[Về kế hoạch chuyển đổi](../plane-demo-porting.md) · [Danh mục endpoint](./endpoints.md)

**Đợt 03** · **122 function gốc** · **4 adapter kế thừa**.

Đánh dấu riêng từng mục sau khi đã chuyển hoặc xác nhận chức năng thay thế tương đương. Nếu chốt ngoài phạm vi, giữ ô trống và ghi quyết định cạnh mục. Đường dẫn sau mũi tên là nơi dự kiến ở Lancity.

Đã có quyền truy cập project, CRUD cơ bản, quản lý thành viên, tự tham gia và rời project, trạng thái mặc định theo batch và form tạo project. Kiểm thử xác nhận cách ly workspace, chống hạ cấp/loại bỏ admin cuối cùng, tạo qua web và mobile, và rollback khi batch thất bại. Các mục về DTO, phân trang, luồng mời, archive, cấu hình và side effect vẫn chờ đối chiếu.
